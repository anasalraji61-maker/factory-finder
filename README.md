# Factory Finder — مُوَرِّد

**منصة عالمية ذكية للتوريد**: تبحث عن المنتجات والمواد الأولية والخطوط الإنتاجية (جديدة ومستعملة)، تتحقق من مصداقية المورّد، وتحسب **الكلفة الكاملة لحد باب الزبون** لأي دولة في العالم.

## ماذا يفعل التطبيق؟

- 🔎 **بحث ذكي** عبر مصادر التوريد (الصين أولاً، ثم أمريكا، ثم أوروبا) — منتجات، مواد أولية، خطوط إنتاج
- 🚢 **حاسبة الكلفة لحد الباب**: نقل داخلي ببلد المصنع ← بحري / جوي / قطار / بري ← الميناء أو المنفذ ← جمارك وضرائب ← نقل داخلي لمدينة الزبون، مع أسعار الصرف
- ✅ **مؤشر ثقة** لكل مورد (أخضر / أصفر / أحمر) مع أسباب واضحة
- 📝 **سوق الطلبات العكسي**: الزبون ينشر طلبه والموردون يقدّمون عروضهم، والمنصة تأخذ عمولة
- 💬 **مراسلات** داخل التطبيق
- 📦 **تتبع الشحنات** (حاوية، بوليصة، شحن جوي، سفينة)
- 🔔 **تنبيهات الفرص** عند نزول السعر أو ظهور مورد أرخص
- 🎙️ **مساعد استيراد ذكي بالعربي**

## التصميم

تطبيق Android + iOS بأسلوب السوشيال ميديا (علي بابا × فيسبوك × إنستغرام) مع شريط سفلي: **استكشف · الطلبات والعروض · الرسائل · الشحن واللوجستيك · حسابي**.
