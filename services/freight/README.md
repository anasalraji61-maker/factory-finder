# freight (port 8114)

Freight-forwarder marketplace. Forwarders (verified companies) **apply**, an admin **approves** them, and they **quote** on buyers' **shipment quote requests**. Buyers **compare** quotes side by side (explainable ranking), **accept** one (idempotent), close the shipment and **rate** the forwarder. Contract: `contracts/openapi/freight.yaml`. Reached through the gateway at `/v1/freight/*`; the admin routes under `/v1/admin/freight/*` are service-local and not routed by the gateway.

- Identity: `X-User-Id` on every route. Forwarder status is **never read from a header or body**: the service resolves it from its own table of admin-approved forwarders (user -> forwarder). Flow: `POST /v1/freight/applications` -> admin `POST /v1/admin/freight/applications/{id}/approve` -> that user can use the forwarder routes (`/v1/freight/forwarders/me*`, quoting). Before approval 403 `forwarder_required`; while suspended 403 `forwarder_suspended`.
- Request: origin/destination country + city/port, cargo text, optional HS code, weight kg and/or volume m3 (exact decimal strings), mode sea/air/road/rail, container type (sea/rail), incoterm, ready date, currency, optional landed-cost ref, quote deadline (1-30 days). Only forwarders whose lanes (`*` wildcards allowed), modes and incoterms match see it (`GET /v1/freight/forwarders/me/inbox`) or can quote on it (others get 404).
- Quote: Decimal total (2 dp) in the request currency, transit days, validity, inclusions/exclusions, optional breakdown lines that must add up exactly, terms. One quote per forwarder per request; revise with `PUT`, withdraw with `POST .../withdraw`.
- Ranking (`ranking.py`, pure): `score = 100 x (w_price x cheapest/price + w_transit x fastest/transit + w_rating x adjusted_rating/5)`; `adjusted_rating = (stars + 3 x 2) / (count + 2)`; defaults 0.5/0.3/0.2. The response carries per-component values, weights, badges (cheapest, fastest, top_rated) and a text explanation; sort by `score|price|transit|rating`.
- State machine: `open -> awarded -> closed`, `open -> closed` (cancel), `open -> expired` (automatic when `expires_at` passes; evaluated lazily on every request-touching call and by `POST /v1/admin/freight/sweep`). Accept is a conditional UPDATE: retrying the same quote is 200, another quote is 409 `already_awarded`. Ratings (1-5, once per shipment) only after completion.
- Screening (`moderation.py`, trimmed copy of sourcing's): links, e-mails, phone numbers, messaging handles and prohibited goods (ar + en) in any free text are rejected with 422 `content_rejected`; the match is never echoed.
- Reports: N distinct eligible reporters (default 3) hide a request or quote (buyers' quotes only reportable by the request owner; requests by parties who can see them; forwarders only by buyers they quoted, never auto-actioned). Admin hide/restore (restore clears reports), suspend/reinstate forwarders, reject applications, list reports.
- Limits: per-user rolling-hour rate limits stored in the DB, caps on open requests per buyer, quotes per request, lanes, applications; keyset pagination (`limit` <= 50).
- Admin: `X-Admin-Token` = `FF_FREIGHT_ADMIN_TOKEN`; 404 when unset.
- Guards: `FF_INTERNAL_TOKEN` (every route except `/health`, `/ready`); `FF_ENV=production` refuses to start without it.

Run: `uvicorn ff_freight.main:app --port 8114` (from `src/`). Test: `../../.venv/bin/python -m pytest`. Migrations: `alembic upgrade head` (SQLite tables are auto-created in dev; PostgreSQL needs the `pg` extra and Alembic).

Env (prefix `FF_FREIGHT_`): `DATABASE_URL`, `DB_AUTO_CREATE`, `ADMIN_TOKEN`, `REPORT_HIDE_THRESHOLD` (3), `MAX_OPEN_REQUESTS_PER_BUYER` (50), `MAX_QUOTES_PER_REQUEST` (50), `MAX_LANES_PER_FORWARDER` (50), `MAX_APPLICATIONS_PER_USER` (5), `MAX_PAGE_SIZE` (50), `WEIGHT_PRICE`/`WEIGHT_TRANSIT`/`WEIGHT_RATING` (50/30/20), `RATE_WINDOW_SECONDS` (3600), `RATE_APPLICATIONS` (3), `RATE_REQUESTS` (10), `RATE_QUOTES` (60), `RATE_RATINGS` (20), `RATE_REPORTS` (20) (0 disables a limit); shared `FF_INTERNAL_TOKEN`, `FF_ENV`, `FF_LOG_FORMAT`.

## Ops
`GET /ready` (unauthenticated): 503 when the database is unreachable. One JSON log line per request (`ts, level, service, request_id, method, path` (route template), `status, duration_ms, user_id`); never query strings, tokens or bodies. `X-Request-Id` is accepted or generated and echoed. Code: `obs.py` (self-contained copy).
