# دليل المالك المختصر — مُوَرِّد (Factory Finder)

للمالك (أنس). ملخص عملي مبني على `docs/STATUS.md` و`docs/RUNBOOK.md` و`docs/DEPLOY.md` و`docs/OWNER_GUIDE.ar.md` (الدليل الموسّع) و`docs/STORE_LISTING.md` و`docs/RELEASE.md` (الإصدار) و`docs/PROVIDERS_AR.md` (تحويل المحوّلات إلى حقيقية) و`docs/MOBILE_GAPS.md` (فجوات التطبيق). حيث لم يُتحقق كتبنا "تحقق". لا أرقام أسعار مخترعة. المستودع عام: لا أسرار فيه أبداً.

حالة الوثائق: 2026-10-16.

## 1) ما الذي بُني؟
- 15 خدمة خلفية خلف بوابة واحدة (gateway :8000): sourcing، logistics، geo، trust، rfq، messaging، tracking، notifications، assistant، demand، payments، media، feed، freight.
- لوحة إدارة (`apps/admin`): مطالبات الموردين، الإشراف، مسودات demand، أحداث الدفع، وثائق التوثيق، وكلاء الشحن، المنشورات.
- تطبيق Flutter (عربي RTL أولاً + إنكليزي): بحث، منتج/مورد، حاسبة الكلفة الكاملة، طلبات وعروض وصفقات، دردشة، تتبع، مساعد، تنبيهات، منشورات، شحن، منتجاتي.
- عقود OpenAPI/JSON Schema، اختبارات، وCI. المراحل 0-3 مكتملة على بيانات وهمية؛ المرحلة 4 (بيانات حقيقية) متوقفة بانتظارك؛ المرحلتان 5-6 هياكل مطفأة.

## 2) حقيقي أم وهمي؟
| الجزء | الحالة |
|---|---|
| الموردون والمنتجات (165/83) | وهمي. الحقيقي فقط ما ينشره موردون داخل المنصة (native) |
| علي بابا/1688/AliExpress/Made-in-China | هياكل مطفأة، صيغ الطلبات غير مؤكدة |
| أسعار الشحن، الرسوم والضرائب (41 دولة)، رموز HS | تقديرية؛ تحتاج مراجعة مخلّص جمركي وشركة شحن |
| أسعار الصرف | وهمية افتراضياً؛ `FF_LOGISTICS_FX_PROVIDER=ecb` مجاني بلا مفتاح |
| التتبع، FCM، SMTP، TronGrid | هياكل مطفأة وغير مجرَّبة |
| الدفع | وهمي؛ USDT/TRON هيكل غير مجرَّب؛ لا بطاقات |
| المساعد | قواعد؛ نموذج لغوي اختياري ومطفأ |
| التطبيق | لم يُجرَّب على هاتف حقيقي؛ مجلدا `android/` و`ios/` غير مرفوعين (يُولَّدان بـ`flutter create .`) |
| docker compose / `make compose-e2e` | لم يُشغَّل فعلياً من قبل؛ أول تشغيل عندك هو الاختبار الحقيقي |
| PostgreSQL 16 | تم التحقق من الهجرات والاختبارات؛ لم يُختبر: التزامن متعدد النسخ، pg_dump/restore، الإنتاج مع TLS |

القاعدة: ما يظهر اليوم عرض تجريبي، لا تعطِ منه أسعاراً أو وعوداً لعملاء.

## ماذا تفعل الآن (قائمة مختصرة)
- [ ] **مفتاح التوقيع**: أنشئ `upload-keystore.jks` على جهازك فقط؛ ملفات `*.jks` و`key.properties` مُدرجة في `.gitignore` ولا تُرفع أبداً. احفظه مع كلمتي المرور في مكانين آمنين، وأضف الأسرار الأربعة في GitHub (التفاصيل: `docs/RELEASE.md`).
- [ ] **إعداد Firebase**: مشروع Firebase، ملف `google-services.json` للتطبيق، وحساب خدمة للخادم؛ بدونها لا إشعارات push حقيقية.
- [ ] **رابط حذف الحساب لـGoogle Play**: صفحة ويب عامة (HTTPS) تشرح كيف يطلب المستخدم حذف حسابه وبياناته؛ يُدخل في Play Console (Data safety). الخادم جاهز (`DELETE /v1/me`)، أما الصفحة والرابط فعليك.
- [ ] راجع مع محامٍ مسودات `docs/legal/` (الخصوصية، الشروط، إجابات Data Safety) وانشرها على رابط عام.
- [ ] شغّل `make venv` ثم `make compose-e2e` على جهازك (لم يُجرَّب docker compose فعلياً) وأرسل النتيجة.
- [ ] شغّل `make compose-check` (يتحقق من ملفات compose والإعدادات قبل التشغيل) و`make secrets-scan` (يفحص المستودع العام بحثاً عن أسرار مسرّبة) قبل أي نشر أو دفع.
- [ ] قرارات عليك اتخاذها: (1) هل نكشف `/metrics`؟ (2) حد تأخر التتبع: 12 أم 24 ساعة؟ (3) تفعيل `require_both_invoices` في RFQ للإنتاج (موصى به: true). (4) سياسة تعداد الحسابات عند التسجيل (409 `account_exists`). (5) الموافقة على إزالة ملفات `.whl` الخمسة المرفوعة في `packages/py-common`.
- [ ] حمّل APK من GitHub Actions (workflow `mobile`) وجرّبه على هاتف حقيقي بالعربية.
- [ ] قدّم على حساب بيانات موردين مرخّص ومزوّد أسعار شحن.
- [ ] احجز موعداً مع مخلّص جمركي (الرسوم/HS) ومحامٍ (الخصوصية، الشروط، العمولة/USDT).
- [ ] ولّد أسرار الإنتاج وضع `FF_ENV=production` على الخادم، ولا تلصقها في المستودع.
- [ ] تذكّر: كل ما يظهر اليوم تجريبي (mock)؛ لا تعطِ منه أسعاراً لعملاء.

## 3) خطوات الإطلاق الفعلية (بالترتيب)
1. **تشغيل محلي**: `cp .env.example .env`، ولّد 3 أسرار (`python -c "import secrets;print(secrets.token_urlsafe(48))"`) لـ`FF_GATEWAY_JWT_SECRET` و`FF_INTERNAL_TOKEN` و`FF_GATEWAY_ADMIN_TOKEN`، ثم `make venv` و`make compose-e2e`. أخبر Claude بالنتيجة.
2. **حساب بيانات موردين مرخّص**: Alibaba Open Platform أو مزود مرخّص. تحقق من الترخيص (عرض وتخزين مؤقت للبيانات والصور). المتغيرات: `FF_SOURCING_ADAPTERS`، `FF_SOURCING_ALIBABA_APP_KEY/APP_SECRET/ACCESS_TOKEN`. اختبر على فئة واحدة أولاً.
3. **مزود أسعار شحن**: `FF_LOGISTICS_FREIGHT_PROVIDER=http` مع `FF_LOGISTICS_FREIGHT_URL` و`FF_LOGISTICS_FREIGHT_API_KEY`. بوابة المرحلة 4: مطابقة 3 مسارات مع عروض فعلية (±15%).
4. **Firebase/FCM**: مشروع Firebase وحساب خدمة (`FF_NOTIFY_PUSH=fcm`، `FF_NOTIFY_FCM_PROJECT_ID`، `FF_NOTIFY_FCM_CREDENTIALS_FILE`). التطبيق لا يحوي مكتبة Firebase بعد: تُضاف مع `google-services.json` قبل أن تصل إشعارات.
5. **SMTP** بنطاقك مع SPF/DKIM: `FF_GATEWAY_MAIL_BACKEND=smtp` + `FF_GATEWAY_SMTP_*` (التحقق من البريد)، و`FF_NOTIFY_EMAIL=smtp` + `FF_NOTIFY_SMTP_*` (الملخص).
6. **USDT على TRON**: محفظتك الخاصة (العنوان العام فقط، لا مفتاح خاص في النظام) + مفتاح TronGrid: `FF_PAYMENTS_PROVIDER=usdt_tron`، `FF_PAYMENTS_USDT_RECEIVE_ADDRESS`، `FF_PAYMENTS_USDT_EXPLORER_API_KEY`، `FF_PAYMENTS_WEBHOOK_SECRET_USDT_TRON`. صيغ TronGrid غير مؤكدة: جرّب بمبالغ صغيرة. سياسة USDT/USD وتسوية التحويلات غير المطابقة قرار منتج مفتوح عندك.
7. **نطاق وTLS**: نطاق + reverse proxy (Caddy/nginx) بشهادة TLS؛ البوابة وحدها مكشوفة؛ اضبط `FF_GATEWAY_TRUSTED_PROXIES` و`FF_GATEWAY_CORS_ORIGINS`.
8. **أسرار الإنتاج بالبيئة فقط**: `FF_ENV=production` (الخدمات ترفض الإقلاع بلا الرموز)، وتتطلب أيضاً `FF_TRUST_VERIFICATION_HASH_KEY` و`FF_MEDIA_SIGNING_KEY`؛ رموز الإدارة لكل خدمة بالقيمة نفسها على البوابة والخدمة. لا تُلصق أسراراً في GitHub أو المحادثات. تدوير المفاتيح: `docs/RUNBOOK.md` القسم 4/5.
9. **PostgreSQL ونسخ احتياطي** خارج الخادم، مع تجربة استرجاع (`docs/RUNBOOK.md`، `docs/DB.md`). Redis إن شغّلت أكثر من نسخة (حدود المعدل في ذاكرة العملية).
10. **اختبار ما بعد النشر**: `FF_E2E_BASE_URL=https://api... make smoke`.
11. **APK**: (دليل الإصدار الكامل في `docs/RELEASE.md`، وworkflow اسمه `mobile-release`) GitHub Actions، workflow `mobile`، حمّل artifact `factory-finder-debug-apk` (يُحفظ 14 يوماً؛ وضع mock). للخادم الحقيقي: Run workflow مع `api_base_url` و`mock=false`. هذا APK تجريبي (debug)، وللمتجر يلزم بناء release موقّع (`.aab`) مع مفتاح توقيع محفوظ خارج المستودع.
12. **iOS**: workflow `ios` يبني للمحاكي بلا توقيع فقط (`--no-codesign`). للمتجر: حساب Apple Developer، Bundle ID، شهادات، TestFlight، ومفاتيح `Info.plist` (`NSPhotoLibraryUsageDescription`، `NSCameraUsageDescription`)، بلا `NSAllowsArbitraryLoads`.
13. **متطلبات المتاجر**: اسم الحزمة النهائي (حالياً `com.factoryfinder`، لا يتغير بعد النشر)، رابط سياسة الخصوصية، Data safety / App Privacy (`docs/STORE_LISTING.md` مسودة)، حساب تجريبي للمراجعة، **شاشة حذف الحساب وتصدير البيانات** (الخادم جاهز: `DELETE /v1/me` و`GET /v1/me/export`، لكن لا شاشة لها في التطبيق)، آلية إبلاغ/حجب للمحتوى. أعد التحقق من متطلبات Google Play للحسابات الجديدة وسياسة Apple للدفع بالعملات الرقمية للسلع المادية.

## 4) قائمة الامتثال القانوني (راجع محامياً)
- [ ] **مخلّص جمركي**: يراجع جداول الرسوم/VAT (غير مُنمذَج: Section 301/IEEPA الأمريكية، المكسيك، سلاسل البرازيل/الهند/نيجيريا، رسوم العراق) ورموز HS ومحتوى مستشار الامتثال؛ وشركة شحن تراجع جدول الأسعار والنقل البري (نقل العراق الداخلي يبدو منخفضاً).
- [ ] **العمولة والدفع**: هل الوساطة وتحصيل العمولة واستلام أموال المشتري وتحويلها يتطلب ترخيصاً (وساطة/خدمات دفع/أصول رقمية) في **العراق** وفي **بلد الشركة** وفي الدول المستهدفة؟ هل USDT مسموح في العراق؟ KYC/مكافحة غسل الأموال والضرائب قبل أول دولار.
- [ ] **سياسة الخصوصية وشروط الاستخدام**: المسودات المعتمدة في `docs/legal/` (`PRIVACY_POLICY.md` و`TERMS_OF_SERVICE.md` و`data-safety-answers.md`) وهي تحلّ محل `docs/PRIVACY_POLICY.draft.md` و`docs/TERMS.draft.md` الأقدم؛ تحتاج مراجعة قانونية؛ عدّل بحسب قانون حماية البيانات في العراق وGDPR إن كان لك مستخدمون أوروبيون؛ اذكر أن سجلات الدفع والصفقات وتدقيق التوثيق تبقى بعد حذف الحساب (بمعرّف مجهول) ومدة بقاء النسخ الاحتياطية.
- [ ] **سياسة الكشط**: واجهات رسمية أو بيانات مرخّصة فقط؛ أي محوّل يقرأ صفحات عامة يحترم robots.txt وحداً أدنى 3 ثوانٍ لكل مضيف، ويعرّف نفسه، ويُعطَّل بالإعداد؛ ممنوع تجاوز CAPTCHA أو تسجيل الدخول أو الجدران المدفوعة. اقرأ شروط كل مصدر قبل التفعيل.
- [ ] **المنصة وسيط**: صياغة المسؤولية عن الجودة والنزاعات والاسترجاع، وإخلاء مسؤولية أن الكلفة والرسوم وHS تقديرية وليست استشارة.
- [ ] **العقوبات والتصدير**: عدم تسهيل تجارة مع جهات أو بضائع محظورة.
- [ ] **السوشيال (المرحلة 5)**: `FF_DEMAND_ENABLED` يبقى مطفأً؛ ردود علنية فقط بموافقة بشرية، بلا رسائل خاصة آلية.
- [ ] **الإدارة**: توكن إداري مشترك واحد (لا SSO)؛ قرر من يملكه وخطة تدويره.

## 5) فئات التكلفة الشهرية (بلا أسعار؛ اطلب عروضاً)
- خادم/VPS لـ15 حاوية (ابدأ صغيراً وراقب `docker stats`).
- PostgreSQL (مُدار أو ذاتي) + نسخ احتياطي خارجي.
- تخزين الصور (قرص أو S3 + نقل بيانات).
- نطاق، TLS، reverse proxy.
- بريد SMTP حسب الحجم.
- FCM (راجع الحصص).
- بيانات الموردين وأسعار الشحن والتتبع: غالباً أكبر بند، تحقق من شروط الترخيص والحصص.
- نموذج المساعد إن فعّلته (رسوم لكل استدعاء؛ الحد اليومي `FF_ASSISTANT_QUOTA_PER_DAY`).
- حسابات المتاجر (Google Play مرة واحدة، Apple سنوي) وجهاز/خدمة بناء macOS لـiOS.
- شركة، محامٍ، محاسب، ومراقبة (uptime/logs).

## 7) أداء (مفتوح)
اختبار الحمل (`make load-test`، 30 عاملاً متزامناً، أجهزة وهمية، SQLite، نواتان) لم يُنتج أخطاء، لكن البحث (p95 ≈ 2.0 ثانية) والمساعد (≈ 3.3 ثانية) تجاوزا حد ثانيتين. ليست أرقام إنتاج؛ المطلوب تحسين البحث قبل الإطلاق (`docs/PERFORMANCE.md`).

ملاحظة صريحة: أسبوعان قد لا يكفيان لموافقات المتاجر وتراخيص المزودين والشركة؛ اعتبرهما هدفاً لإطلاق تجريبي مغلق وليس عاماً.
